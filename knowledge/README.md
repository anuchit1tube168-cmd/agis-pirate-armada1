# Knowledge Factory

This directory is the durable knowledge layer for AGIS.

## Flow
```
Source Registry
→ Channel Scan
→ Clip Queue
→ Transcript/Metadata Resolution
→ Structured Extraction
→ QA Review
→ Experiment / Skill
→ AGIS Evolution
```

## Important
The repository stores derived knowledge and evidence links, not copied transcript archives by default.

## Source hierarchy
1. User-owned/provided material.
2. Official docs / direct primary sources.
3. Firsthand interviews.
4. Credible reporting.
5. Commentary/predictions.

The more consequential the decision, the higher the evidence bar.

## “Learn every clip” does not mean “believe every clip”
Every item is indexed. Only validated lessons alter project strategy or AGENTS.md.
