# DATA LEARNING OS — THE CORE ASSET

## Principle
AGIS does not get smarter because it stores more text.
AGIS gets smarter when data is structured around decisions, outcomes, corrections and repeated patterns.

## Data hierarchy

### L0 — Raw Source
Links, files, transcripts, logs, customer notes, test outputs.

### L1 — Structured Observation
Who/what/when/context/result.

### L2 — Knowledge
Claims, concepts, mechanisms, failure modes, causal hypotheses.

### L3 — Evaluation Data
Expected output, actual output, pass/fail, error class, reviewer correction.

### L4 — Decision Data
What decision was made, why, evidence used, confidence, result.

### L5 — Skill Data
Reusable rule/checklist/template/test that improved performance.

### L6 — Business Data
Revenue, pipeline, ACV, cost, time saved, ROI, retention, conversion.

### L7 — Strategic Memory
Patterns proven across multiple workflows/customers.

## What must be logged from every important job
- input/context
- output
- agent/model/tool
- elapsed time
- human time
- cost
- acceptance test
- pass/fail
- failure mode
- human correction
- final outcome
- reusable asset produced
- customer/business effect
- evidence link

## Learning value
High-value data usually contains:
- correction;
- outcome;
- comparison;
- failure;
- decision;
- repeated usage;
- measurable before/after.

Low-value data:
- copied news with no implication;
- long transcript with no extraction;
- duplicate notes;
- unverified prediction;
- logs with no outcome.

## Data → Agent learning
```
DATA
→ PATTERN
→ RULE CANDIDATE
→ EVAL
→ IMPROVEMENT
→ RETEST
→ PROMOTE
```

No automatic rule promotion from raw data alone.

## Data moat
The long-term moat is not the model.
It is:
- proprietary workflow outcomes,
- human corrections,
- eval cases,
- customer process knowledge,
- integration behavior,
- permission patterns,
- distribution learning,
- ROI evidence.

## Data safety
- Separate customer-private data from generic learning.
- Do not train cross-customer behavior on confidential content without authorization.
- Prefer abstracted patterns over copying source data.
- Preserve provenance.
- Keep permissions and audit trails.
