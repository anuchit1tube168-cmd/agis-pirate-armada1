# DAILY TRAINING LOOP — TEACH THE AGENTS

## Principle
Training happens from evidence produced by work, not from motivational prompting.

## Every day
1. Read yesterday's failed/slow/expensive jobs.
2. Select one failure pattern worth learning.
3. Write root cause in one sentence.
4. Find an existing AGIS skill/pattern before inventing a new one.
5. Update exactly one of:
   - agent instruction,
   - checklist,
   - test,
   - template,
   - reusable code pattern,
   - retrieval context.
6. Re-run the relevant test.
7. Compare before/after metric.
8. Promote the lesson only if improvement is measurable.
9. Record the lesson in Training Log.
10. Retire rules that no longer help or create contradictions.

## Training record schema
- date
- agent
- job_id
- failure/constraint
- root cause
- lesson
- artifact changed
- test before
- test after
- cycle time before/after
- cost before/after
- promoted? yes/no
- reviewer

## Skill levels
L0 — instruction only  
L1 — checklist exists  
L2 — reusable template exists  
L3 — automated test exists  
L4 — repeated success across 2+ jobs  
L5 — reusable across 2+ customers/workflows

Do not call a capability “mastered” before L4.
