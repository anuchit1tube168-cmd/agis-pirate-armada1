# YOUTUBE → R&D BULLET SYSTEM

## Purpose
Use selected YouTube clips as an intelligence source for AGIS R&D.

## Relevance gate
Process deeply only when the clip contributes to one or more:
- AI agents / autonomous workflows
- OpenAI / frontier model strategy
- model capability / eval / safety
- AI coding / automation
- future of work / digital labor economics
- AI business models / distribution
- data advantage / memory / RAG
- security / permissions / governance
- founder leverage / productivity
- enterprise AI adoption
- sales / product / customer discovery relevant to $10M

Other clips may be indexed but remain NO ACTION.

## Bullet extraction format

### 1. Core thesis
- 3–7 bullets.

### 2. How the speaker thinks
- mental model;
- assumptions;
- decision logic;
- trade-offs;
- what they optimize for.

### 3. Mechanisms
- what causes what;
- where leverage appears;
- where bottlenecks appear;
- what could compound.

### 4. Evidence vs prediction
- FACT / FIRSTHAND / REPORTING / OPINION / FORECAST / HYPOTHESIS.

### 5. AGIS relevance
- what we should learn;
- what we should NOT copy blindly;
- what project layer it changes.

### 6. Build implications
- what system/component/agent/workflow could be created.

### 7. Agent implications
- what new role is needed;
- what existing agent should learn;
- what job description changes.

### 8. R&D questions
- 1–3 testable hypotheses.

### 9. Experiment
- smallest experiment;
- expected result;
- metric;
- acceptance threshold.

### 10. Skill extraction
- checklist/template/rule/eval if proven.

### 11. Business leverage
- revenue;
- distribution;
- cost;
- speed;
- reuse;
- retention;
- risk.

### 12. Final decision
- PROMOTE
- EXPERIMENT FIRST
- WATCH
- NO ACTION

## Key principle
Do not “learn every idea.”
Learn only the ideas that survive the relevance gate and improve measurable work.

## Channel strategy
For channels like The Diary Of A CEO:
- index all discovered clips if technically practical;
- deeply process only relevant AI/business/system-thinking clips;
- prioritize direct practitioners, primary sources and evidence-rich interviews;
- use multiple guests to triangulate contested claims.

## Outcome
Every relevant clip should end as one of:
- R&D experiment,
- agent improvement,
- skill,
- workflow,
- evaluation,
- product idea,
- distribution experiment,
- no-action decision.
