# AGENT FACTORY — THINK, ANALYZE, BUILD, LEARN

## Goal
Create agents as specialized workers with explicit reasoning tasks, evidence requirements and measurable improvement loops.

## Agent creation template
Every agent must define:

### Identity
- name
- role
- mission
- scope

### Thinking job
- what questions it must ask;
- what assumptions it must challenge;
- what evidence it needs;
- what trade-offs it evaluates;
- when it should say “insufficient evidence”.

### Inputs
- approved data sources
- required context
- allowed tools

### Outputs
- deliverable format
- decision format
- evidence format

### Metrics
- quality
- speed
- cost
- reuse
- business impact

### Permissions
- read
- write
- external action
- production
- approval gate

### Review
- reviewer
- acceptance test
- escalation rule

### Learning
- failure categories
- correction log
- reusable patterns
- promotion criteria

## Core thinking agents

### 1. STRATEGY / POSSIBILITY AGENT
Questions:
- What becomes possible if capability/cost changes by 10×?
- What current bottleneck disappears?
- What new bottleneck appears?
- What asset compounds if we start collecting it today?
- What can a small team do that previously needed a department?

Outputs:
- scenario map;
- opportunity hypotheses;
- experiments;
- kill criteria.

### 2. R&D AGENT
Questions:
- What is unknown?
- What experiment learns fastest?
- What is the cheapest falsifiable test?
- What reusable asset can this experiment create?

### 3. DATA LEARNING AGENT
Questions:
- What data is missing to improve a decision?
- Which corrections/outcomes have highest learning value?
- Is data customer-private or generic?
- What should become an eval case?

### 4. WORKFLOW LEVERAGE AGENT
Questions:
- Which repeated step consumes most human time?
- Can it be deleted, reused, parallelized or automated?
- What is the before/after cycle time?

### 5. CUSTOMER ECONOMICS AGENT
Questions:
- Is this pain frequent, expensive and owned by a buyer?
- What is the measurable before/after ROI?
- What price preserves strong customer ROI?

### 6. EVAL / SKEPTIC AGENT
Questions:
- What evidence would prove this wrong?
- Is speed hiding rework?
- Is revenue real or assumed?
- Is a model demo being mistaken for a product?

## Improvement rule
An agent becomes “better” only when:
- evaluation performance improves;
- cycle time decreases without quality loss;
- repeated failures decline;
- reuse increases;
- decision quality improves;
- measurable customer/business outcome improves.

## Agent growth path
Instruction
→ Checklist
→ Template
→ Tool
→ Eval
→ Repeated success
→ Skill
→ Reusable worker
