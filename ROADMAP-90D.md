# ROADMAP-90D — AGIS $10M LEVERAGE

## Days 1–10 — Baseline + Money
- Lock target definition and target date.
- Build $10M math model.
- Select initial ICP.
- Select Golden Workflow.
- Measure baseline time/cost/error.
- Create Agent Registry and Job Queue.
- Create benchmark/evaluation set.

## Days 11–30 — Golden Workflow
- Build end-to-end workflow in staging.
- Add permissions + audit + human gates.
- Instrument cost/latency/success.
- Reuse AGIS patterns/connectors.
- Begin customer discovery and paid pilot offer.
- Target: first paying design partner and one measurable outcome.

## Days 31–45 — Repeat
- Deploy to second context/customer.
- Reuse >=40%.
- Fix top failure modes.
- Create deployment checklist/template.
- Measure time-to-value.

## Days 46–60 — Productize
- Third deployment.
- Reuse >=60%.
- Case study with measured before/after data.
- ROI calculator.
- Harden evaluation/security.
- Target: 2 paying design partners and expanding pipeline.

## Days 61–75 — Distribution
- Systematic outbound/content/partners.
- Two or more measured distribution experiments/week.
- Track real funnel conversion.
- Productize integrations and onboarding.
- Reduce founder delivery time.

## Days 76–90 — Scale Gate
- 3 paying design partners target.
- Deployment path toward <7 days.
- Verified ROI cases.
- Repeatable offer, sales, onboarding, delivery.
- Update $10M model using actual ACV, conversion and costs.
- Decide: scale, narrow ICP, raise price, improve product, or change channel.

## Daily cadence
Morning: DO THE MATH → assign highest-leverage jobs.  
Work cycle: execute/test/log.  
Review: QA + CFO + Security review.  
Learning: extract one durable lesson/skill/template when evidence supports it.

## Weekly gate
Every 7 days answer:
- What moved revenue/pipeline?
- What reduced cycle time?
- What became reusable?
- What failed twice?
- What should be deleted/backlogged?
- Is the $10M path mathematically more credible than last week?
