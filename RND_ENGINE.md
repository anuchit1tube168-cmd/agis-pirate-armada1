# R&D ENGINE — AGIS $10M

## Mission
Turn real work, customer problems, failures, research and selected YouTube knowledge into reusable R&D assets that improve AGIS and increase the probability of reaching $10M.

## What enters R&D
Only items relevant to at least one:
- Revenue
- Customer ROI
- Workflow automation
- Agent capability
- Data advantage
- Integration
- Evaluation
- Distribution
- Permissions / audit
- Time compression
- Reuse
- Learning velocity

Everything else is WATCH or NO ACTION.

## Core R&D loop

```
WORK / CUSTOMER / YOUTUBE / FAILURE
→ OBSERVATION
→ BULLET EXTRACTION
→ CLAIM CLASSIFICATION
→ HYPOTHESIS
→ EXPERIMENT
→ RESULT
→ DECISION
→ SKILL / TEMPLATE / TEST / AGENT RULE
→ REUSE
→ MEASURE BUSINESS IMPACT
```

## Required R&D record
- RND_ID
- source
- problem/opportunity
- observed evidence
- key bullets
- hypothesis
- expected leverage
- experiment
- acceptance test
- metric
- result
- decision
- asset created
- affected agent(s)
- reusable across what?
- revenue/cost/time implication
- confidence
- next experiment

## R&D priority score

```
Priority =
(Revenue Impact
× Reuse Potential
× Evidence Strength
× Strategic Fit)
/
(Effort × Risk × Time-to-Learn)
```

Use simple 1–5 scores. The score prioritizes experiments; it does not prove revenue.

## R&D output types
1. Skill
2. Agent job pattern
3. Checklist
4. Evaluation
5. Dataset
6. Connector
7. Workflow template
8. Product feature
9. Sales/distribution experiment
10. Customer insight
11. Architecture decision
12. Kill decision

A good R&D system learns what NOT to build.

## Daily R&D rule
Every workday, capture at least one of:
- a new validated learning,
- a disproven assumption,
- a reusable pattern,
- a measured bottleneck,
- a customer signal,
- a failed approach worth preventing.

Do not force an insight when no evidence exists.

## Weekly R&D review
- What new knowledge changed a decision?
- What skill became reusable?
- Which agent improved measurably?
- Which workflow compressed in time?
- Which hypothesis failed?
- Which dataset became more valuable?
- Which customer signal affects pricing/offer?
- Which R&D item should become product/IP?
